# Security Policy

## Supported Versions

LabExT is unmaintained and has no active maintainers. No versions are supported,
including existing releases and the code on the default branch. Security patches,
dependency updates, bug fixes, and compatibility updates are no longer provided.

The source code, existing releases, and documentation remain available for existing
users and community forks. Their availability does not imply ongoing security support.

## Reporting a Vulnerability

This project does not provide an actively monitored security reporting channel.
Vulnerability reports, issues, and pull requests may receive no response. Do not
expect acknowledgement, investigation, a fix, or a coordinated disclosure timeline
from this project.

Organizations continuing to use LabExT should assess its dependencies, security,
and suitability for their laboratory environment, and arrange their own security
review and maintenance. New deployments are discouraged. Community-maintained forks
are welcome under the existing license.
